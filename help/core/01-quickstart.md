# 快速上手

## 第一步：登录

启动 VeroRun 桌面应用，使用本地账号登录。首次启动会自动初始化本地核心与数据库。

> 本地核心默认监听 `127.0.0.1:8084`，无需联网即可登录与使用基础功能。

## 第二步：配置 AI 模型

进入左侧导航 **智能与知识 → AI 设置**，填入你自己的模型 API Key：

- OpenAI / DeepSeek / 通义千问（DashScope）/ OpenRouter / SiliconFlow / Gemini / Grok / Anthropic / 腾讯混元 等任选
- 也可配置本机 Ollama 本地模型，完全离线运行
- 填好密钥后可点 **对齐供应商（拉取全量）**，一次性把各家最新模型目录同步进来（详见《AI 设置》）

不填 Key 也能用基础功能，但 AI 分析类能力会受限。

## 第三步：认识主界面

左侧导航分四组，常用入口：

| 分区 | 入口 | 作用 |
|---|---|---|
| 股票分析 | 投研总览 / 个股工作台 | 行情看盘与个股研究 |
| 股票分析 | 自选与信号 / 告警中心 | 自选列表、买卖信号、价格与指标告警 |
| 智能与知识 | 智能对话 | 与 AI Agent 自然语言交互 |
| 智能与知识 | 认知进化 | 查看 AI 的记忆与反思沉淀 |
| 智能与知识 | 知识中心 | 词条 / 文档 / 研报 三类资料库 |
| 数据源管理 | 数据源管理 / 网络出口 / 数据备份 | 数据源、出网通道、备份 |

> **设置**（外观、语言、运行档位）点右上角齿轮图标进入。

## 第四步：试一次对话

进入 **智能对话**，直接输入问题，例如：

- "帮我看看当前自选股的整体表现"
- "把这篇 PDF 的核心观点总结一下"（先在知识中心上传）
- "为什么贵州茅台今天放量上涨？"

AI 会自动调用合适的 Agent 角色与数据源，回答时附引用来源。

## 第五步：设置外观与偏好

点右上角齿轮进入 **设置**，可调整：

- 浅色 / 深色 / 跟随系统
- 主题风格（精密 / 夜行 / 极简）
- 界面密度（舒适 / 紧凑）
- 简体中文 / English

## 常见问题

- **启动慢？** 首次启动要加载本地核心与数据库，约 1-3 分钟属正常；后续冷启动约 30 秒。
- **没有 AI 回复？** 检查 AI 设置里的 Key 是否填对、网络是否可达；或切换到其他模型试试。
