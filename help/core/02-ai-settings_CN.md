# AI 设置

AI 设置是你接入大模型、查看模型清单与用量健康的地方。左侧导航 **智能与知识 → AI 设置** 进入。

## 八个模块

AI 设置页由八个模块组成：

- **供应商密钥** —— 填入 / 修改各家模型的 API Key。**这是本页唯一可编辑的模块。**
- **供应商** —— 维护供应商**基础信息 + 调用端点地址 + 类型**（自研 / 聚合）。新增业务能力只需在此登记，内核保持稳定。
- **模型管理** —— 选定供应商后，**仅需对齐供应商侧的 Model ID** 即可完成模型与供应商的绑定；调用端点继承供应商，无需逐模型重复填写。
- **智能体矩阵** —— 查看各业务域（金融 / 内容 / 运维 …）分别由哪个角色、哪个模型承接；并可**以角色为主体添加模型密钥**（见下）。
- **提示词** —— 查看按角色与场景分组的系统提示词。
- **LLM 配额** —— 查看四级配额（用户 > 模型 > 模块 > 全局，优先级从高到低）。
- **Token 用量** —— 按模型、按模块查看实时消耗。
- **模型健康** —— 查看各供应商的连通性、失败计数与熔断状态。

> 除「供应商密钥」「供应商」「模型管理」「智能体矩阵」的配置动作外，其余模块为**只读展示**，数据来自本机内核的 AI Hub。要调整配额、提示词等配置，需在内核侧进行。

## 供应商维护（基础信息 + 端点 + 类型）

1. 进入 AI 设置 → **供应商** → 点 **_+ 新建供应商_**
2. 填写名称、slug（唯一标识）、描述、**调用端点地址**，并选择**类型**：
   - **自研（vendor）** —— 只提供自家模型；
   - **聚合（aggregator）** —— 一家接入、背后聚合多家模型（如阿里百炼、腾讯 TokenHub、百度千帆、OpenRouter、硅基流动）。
3. 保存即生效。名下有模型或已配置 API Key 的供应商不可删除，需先清理其模型 / Key。

## 模型维护（只对齐 Model ID）

1. 在供应商卡片上点 **_+ 添加模型_**
2. **只需填写供应商侧的 Model ID**（如 `deepseek-chat`、`hunyuan-turbos`），无需填写端点或显示名——显示名默认即 Model ID，端点自动继承所属供应商。
3. 保存后模型与供应商的绑定关系即完成；被 Agent 角色密钥条目引用的模型不可删除。

## Agent 矩阵密钥绑定（多密钥 · 多供应商 · 多模型）

以**角色为主体**管理模型密钥：任意角色都可以挂多把 Key、多个模型、多个供应商。

1. 进入 **智能体矩阵**，在目标角色上点 **_🔑 模型密钥_**
2. 通过二级菜单逐步添加一条：
   - **供应商** → **该供应商下的模型**（联动）→ **Key 角色**（`primary` / `backup` / `dedicated`）→ **填入 Key**
3. 一条不够，重复添加即可；每条都可单独删除，卡片顶部汇总「N 条 · N 个供应商 · N 个模型」。

内置**密钥池**，基础能力开箱即用：

- **自动轮换** —— 同供应商的多把 `primary` Key 轮询使用，分摊限流配额；
- **故障降级** —— `primary` 全部限流时启用 `backup`；主模型故障时自动切换到该角色的其他模型条目；
- **429 冷却** —— 命中的 Key 写入冷却并自动跳过，冷却状态跨进程（多 worker）共享；条目状态列显示「正常 / 冷却中」。

## 填入模型 Key

1. 进入 AI 设置 → **供应商密钥**
2. 选择供应商，填入你的 API Key
3. 保存后立即生效，无需重启

- 支持 OpenAI、DeepSeek、Gemini、Grok、Anthropic、Ollama、智谱 GLM、KIMI、Edge-TTS 等**自研厂商**端点。
- 也支持**聚合平台**（阿里百炼、腾讯 TokenHub、百度千帆、OpenRouter、硅基流动）代理的第三方模型；供应商列表中以「聚合 / 自研」标签区分。
- Key 加密存储在本机系统密钥链（Windows DPAPI / macOS Keychain），不明文落盘。

## 对齐供应商（拉取最新模型目录）

供应商上新模型后，不需要手工登记：

1. 进入 **模型管理** → 点 **对齐供应商（拉取全量）**
2. 系统逐家调用其官方 `/models` 接口，拉取实时模型目录，与本地已登记清单求差
3. 逐条审阅差异并决策：
   - **远端新增** → 选「新增入库」
   - **远端已下线** → 选「置灰」（不硬删，保留引用完整性）
   - 不关心的条目 → 选「忽略」
4. 点「应用全部决策」落库

几个要点：

- 新增模型里，**纯文本对话模型默认启用**；图像 / 视频 / 音频 / 语音 / 3D / OCR / 视觉 / 嵌入（embedding）/ 重排（rerank）类模型**入库但置灰**，需要时在模型管理里手动启用。
- 本地已有的**嵌入模型**若被判定为"远端已下线"，默认**忽略**——避免一键应用误停知识中心的向量检索通道。
- 扫描会跳过**缺少 Key 或不可达**的供应商；某一家失败不影响其余家。
- 列表可按能力筛选（全部 / 文本 / 嵌入 / 其他），方便在长清单里定位。

## 本地模型（Ollama）

如果你想完全离线运行：

1. 本机安装 Ollama
2. `ollama pull qwen2.5:7b`（或其他模型）
3. AI 设置里供应商选 Ollama，端点默认 `http://127.0.0.1:11434/v1`，Key 留空
4. 保存后所有 AI 推理走本机，数据不出这台机器

## 注意

- 商业数据源 Key（tushare、FMP、Polygon）在 **数据源管理** 里配置，不在这里
- AI 设置里的 Key 是**模型 API Key**，两者不要混
