# 知识中心

知识中心是让 AI 基于"你自己的资料"回答的地方。左侧导航 **智能与知识 → 知识中心** 进入。

页面内含三个页签，各自独立取数、互不共享：

| 页签 | 内容 | 说明 |
|---|---|---|
| **词条库** | 轻量文本条目：标题 / 内容 / 分类 / 作用域 / 优先级 | 手工维护，适合放零散事实与口径；可置**系统级**或**用户级** |
| **文档库** | 上传整份文档，自动切片建索引 | 支持语义检索与问答，依赖本地知识库后端 |
| **研报库** | 归档研究报告 | 按标的与报告类型组织，支持检索与问答 |

> 产品自带的操作手册（含本手册）随安装包离线提供，只读；无需你维护。

## 文档库：上传与问答

**上传**

1. 进入 **知识中心 → 文档库 → 研报列表**，点击或拖拽文件到上传区
2. 支持 PDF、DOCX、TXT、MD、PPTX，单文件上限 **50 MB**；可填股票代码、报告类型、分析师
3. 上传后自动抽取分块并建立语义索引，状态依次为 **待处理 → 处理中 → 就绪**（失败会标红）

**语义检索**

- 切到 **语义检索** 页签，输入关键词；可限定股票代码缩小范围
- 结果按**相关度**排序，点击可定位到原文档页

**智能问答**

- 切到 **智能问答** 页签，基于已上传的资料提问，例如：
  - "这份研报的核心逻辑是什么？"
  - "总结这份文档提到的付款节点"
- 回答下方给出 **引用来源**，可对照原文核对

## 词条库

- **新增 / 编辑 / 删除**条目：填标题、内容（Markdown 或纯文本）、分类、关键词
- **作用域**分两级：系统级（全局可见）、用户级（仅自己）
- 列表显示**命中次数**，便于判断哪些条目真正被用上
- 适合沉淀口径类的短知识（如"公司统一使用的估值口径"），与整篇文档互为补充

## 与智能对话的区别

- **知识中心问答**：严格基于你上传的资料，答不上来就说不知道
- **智能对话**：可以联网查行情、调用工具、多步推理，但也会综合多种信息

在智能对话里可用"**知识库问答**"建议卡（提示词为"请基于本地知识库检索并回答：…"），让 AI 优先走你的资料。

## 隐私

- 文档只存在本机数据库，不上传云端
- 上传时走本地或你配置的 embedding 模型，不会把文档内容发给第三方
- 删除文档后，其向量索引同步清除

## 排障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 上传后处理失败 | 文件过大或格式不支持 | 换 PDF / DOCX / TXT / MD / PPTX，控制在 50 MB 以内 |
| 问答答得偏 | 文档内容杂、切片不理想 | 改用更聚焦的文档重传，或拆分成多份 |
| 检索没有结果 | 嵌入模型不可用 | 到 AI 设置检查嵌入模型凭据 |
| 提示"知识库后端未启用" | project_workspace 插件未启用 | 按页面提示一键启用，或到插件中心启用 |
