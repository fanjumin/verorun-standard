# 产品概览

VeroRun AI 是一套本地优先、客户自持的 AI 操作系统，面向投研、科研与个人知识工作场景。与常见的"云端 AI 问答工具"不同，VeroRun 把多 Agent 协作、知识检索、流程编排、模型接入与资产保护固化在本地引擎里——你的数据默认只存在这台机器上。

## 核心能力

- **多 Agent 协作**：任务自动拆解为多个专职角色并行处理，生成与评审分离，结论可追溯。
- **本地优先**：会话、文档、记忆默认落本机磁盘，离线可用；网络恢复后按需同步。
- **插件化**：投研、科研、邮件、IM 通知、知识库、备份等能力以插件形式装配，内核保持稳定。
- **认知进化**：AI 从每一次结论中反思沉淀，长期记忆越用越贴合你的工作风格（详见《认知进化》章节）。
- **证据链反幻觉**：每条 AI 结论附数据来源，缺失如实标注，宁可报错也不编造。

## 桌面端功能分区

金融版桌面端的左侧导航自上而下分四组：

| 分区 | 入口 | 作用 |
|---|---|---|
| **股票分析**（主区） | 投研总览 / 个股工作台 / 自选与信号 / 告警中心 / 神经中枢 / 宏观 EDB / 交易台 | 行情看盘、个股研究、信号与告警、多源融合、宏观数据、仿真交易 |
| **智能与知识** | 智能对话 / 认知进化 / 知识中心 / 资讯管理 / 工作流 / AI 设置 | 与 AI 交互、记忆沉淀、资料库、资讯采集、流程编排、模型配置 |
| **数据源管理** | 数据源管理 / 网络出口 / 数据备份 | 数据源凭据与指数范围、出网通道、备份与恢复 |
| **联系与通知** | 通讯频道 / 邮件服务 | 告警的外发通道（IM / 邮件） |

> **设置**不在左栏单列，点右上角齿轮图标或用户菜单直达。

## 两种使用形态

| 形态 | 说明 |
|---|---|
| 桌面个人版 | 单个安装包，内嵌完整引擎与插件，离线可用，数据默认落本地 |
| 企业版 | 服务器集中部署，客户机连接，支持多用户、权限与审计 |

本手册以桌面个人版为主。

## 数据与隐私

- 所有文档、会话、记忆默认存在本机用户数据目录，不上传任何云端。
- 商业数据源（tushare、FMP、Polygon 等）的 API Key 由你自行填入，VeroRun 不代发、不收集。
- 输出为研究信息与风险提示，不构成投资建议，不承诺收益。
