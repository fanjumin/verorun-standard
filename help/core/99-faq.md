# 常见问题

## 安装与启动

**Q: 启动很慢正常吗？**
A: 首次启动要加载本地核心、数据库、插件，约 1-3 分钟。后续冷启动约 30 秒。如果超过 5 分钟，检查是否被杀毒软件拦截。

**Q: 可以不联网用吗？**
A: 可以。基础对话、历史会话、本地资料问答都能离线。AI 推理需要配置 Ollama 本地模型；联网行情、外部新闻类功能需要网络。

**Q: 数据存在哪里？**
A: 默认在本机用户数据目录（Windows: `%APPDATA%/VeroRun Finance/`）。卸载时可选择是否保留。

## AI 与模型

**Q: 不填 API Key 能用吗？**
A: 基础界面、历史会话、本地资料浏览能用。AI 分析、对话生成需要 Key，或配置 Ollama 本地模型。

**Q: 支持哪些模型？**
A: OpenAI、DeepSeek、通义千问、OpenRouter、SiliconFlow、Gemini、Grok、Anthropic、腾讯混元、Ollama 等。可在 **AI 设置** 里切换，并用"对齐供应商"一键同步各家最新模型目录。

**Q: AI 会编造数据吗？**
A: 系统设计上：每条结论挂证据链，数据缺失明确标注"unavailable"，商业授权数据进 LLM 前过许可闸门。宁可报错也不编造。

## 知识与记忆

**Q: "知识中心"和"认知进化"有什么区别？**
A: 知识中心是你**主动**上传或维护的资料（词条 / 文档 / 研报），AI 严格基于资料回答；认知进化是 AI 从日常交互中**自动**沉淀的隐性经验（记忆与反思），越用越贴合你的习惯。

**Q: 我的资料会上传到云端吗？**
A: 默认不会。文档、会话、记忆都在本机数据库。只有你主动配置的云同步或外部通知（邮件、IM）才会出网。

**Q: API Key 安全吗？**
A: 加密存在本机系统密钥链（Windows DPAPI），不明文落盘。

## 投研相关

**Q: 输出是投资建议吗？**
A: 不是。所有输出为研究信息与风险提示，不构成投资建议，不承诺收益。

**Q: 支持哪些市场？**
A: A 股为主；美股、港股日线行情（需自备 Polygon / FMP Key）；期货、期权、基金、债券多资产。

**Q: 免费行情和付费行情有什么区别？**
A: 免费源（akshare、新浪、腾讯）零成本但无 SLA，字段可能随上游变化。填入 tushare 等付费 Key 后自动升级为有 SLA、含复权口径。

## 其他

**Q: 怎么备份？**
A: 左侧导航 **数据源管理 → 数据备份**（数据保险箱，由 vault 插件承载）。支持全量/增量备份、压缩、AES-256-GCM 加密、保留天数与多目标存储（本地目录、S3、OSS 等），并可随时下载归档。首次使用需先启用该插件。

**Q: 遇到 Bug 怎么办？**
A: 在 **智能对话** 里说"帮我看看日志"，本地系统管理员 Agent 会协助诊断；也可在设置中查看运行档位与版本信息。
