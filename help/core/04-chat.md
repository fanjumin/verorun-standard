# 智能对话

智能对话是与 AI Agent 自然语言交互的主入口。左侧导航 **智能与知识 → 智能对话**。

## 基本操作

- 输入问题，回车发送；支持多轮对话，AI 会记住上下文
- 会话自动保存在本机，左栏可切换历史会话、新建与重命名
- **讨论模式**：多 Agent 协作（Planner → Reviewer → Decider → 执行），关键步骤会弹出**人工审批**，你确认后才继续

## 指令

- `@系统管理员`：直达本地系统管理员 Agent（输入框提示里就有）
- 自然语言即可，不需要记命令

## 附件

- 可附**文本类**文件（≤ 2 MB），内容随消息一起发送
- 更大的资料建议先上传到 **知识中心**，再让 AI 基于资料回答

## 建议卡

新会话会给出快捷建议卡，金融版常用：**生成研报 / 个股诊断 / 组合复盘 / 宏观解读 / 知识库问答**。

## AI 能做什么

- 查行情、看自选股表现
- 分析个股基本面、技术面
- 多空辩论（AI 自己跟自己辩论后给结论）
- 总结文档、对比资料
- 定时任务（"每个交易日收盘后帮我跑一下自选股"）
- 排查本地服务、解释日志

## 回答的可信度与反馈

- AI 结论附**证据链**：财报、资金流、新闻、估值四类来源
- 数据缺失时会明确说"这个数据拿不到"，不编造
- 可对回答点 **赞 / 踩** 反馈
- 满意的回答可一键 **入库知识库**，沉淀为词条供后续复用
- **所有输出为研究信息，不构成投资建议**

## 会话管理

- 历史会话自动保存在本机
- 支持重命名、删除

## 离线使用

- 无网络时，基础对话与历史会话可用
- 配置 Ollama 本地模型后，AI 推理也能离线跑
- 联网行情类功能需要网络
