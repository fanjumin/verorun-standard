# 认知进化

认知进化（品牌名 **CogEvolution**，由 `memory_engine` 插件在后台承载）是 VeroRun 让 AI "越用越懂你"的能力：系统把每一次对话、结论与反馈沉淀为长期记忆，并从中反思、优化自身的回答策略。它不是一次性的模型训练，而是持续在本地发生的"记忆 → 反思 → 优化 → 行为进化"闭环。

## 它解决什么问题

- 普通 AI 每次对话都从零开始，记不住你的偏好、项目背景与工作习惯。
- 认知进化让 AI 长期保留对你有价值的上下文，并在后续对话中主动复用，减少重复交代。

## 四个核心机制

| 机制 | 作用 |
|---|---|
| 记忆沉淀（Sedimentation） | 把有价值的结论、偏好、事实写入长期记忆，跨会话保留 |
| 反思学习（Reflexion） | AI 对自身结论做复盘，识别偏差与遗漏，形成改进经验 |
| 遗忘与衰减（Forgetting） | 过时或低价值的记忆按策略衰减清理，避免噪声累积 |
| 提示词进化（Prompt Evolution） | 基于沉淀经验优化自身的提示策略，使回答更贴合你的场景 |

> 上述机制由后台定时任务自动驱动（例如每日低峰期依次执行 反思 → 沉淀 → 遗忘 三类作业），无需手动触发。

## 在哪里查看

左侧导航 **智能与知识 → 认知进化**。页面按三块组织：

| 分区 | 看什么 |
|---|---|
| **记忆** | AI 记住的内容，按"事实 / 教训 / 偏好 / 技能"四型分类计数，可搜索 |
| **反思** | AI 对自身结论的复盘记录（结论 / 行动 / 评分） |
| **知识沉淀** | 高价值记忆的待审队列；点 **批准入知识库** 后写入全站知识库（词条） |

页面顶部另有指标卡（记忆总量 / 反思记录 / 待审沉淀 / 长期记忆）与一条"累计习得量"曲线——它是每轮沉淀的记忆与反思条数的**累计代理量**，不是能力评分；轮次不足时呈空态。队列为空时可点 **立即扫描沉淀** 触发一次扫描。

> 若页面提示"记忆服务不可达"，多为 `memory_engine` 插件未启用或本地核心未重启；启用插件后重启核心即可恢复。

## 与知识中心、智能对话的关系

- **知识中心**：你主动上传或维护的资料，AI 严格基于资料回答。
- **智能对话**：你与 AI 实时交互的主入口。
- **认知进化**：AI 在这两者之外，自动从交互中沉淀的"隐性经验"——它让同样的提问，下次回答得更准、更贴你。

## 数据与隐私

- 所有记忆、反思记录默认存在本机用户数据目录，不上传任何云端。
- 认知进化产生的是研究辅助信息，不构成投资建议，不承诺收益。
