# 短信服务 — 使用指南

本指南面向 **运营**，指导你配短信验证。

---

## 1. 前置条件

- 阿里云短信账号或 Twilio 账号。

---

## 2. 启用

1. **Security → SMS Management**。
2. **设置** → 填阿里云（或 Twilio）凭证。

---

## 3. 模板

- **模板 → 新建** → 名称、内容带 `${code}` 变量。
- 提交给 provider 审核。

---

## 4. 测试

- **测试发送** 输手机号 → 验证到达。

---

## 5. 日志

- **日志** → 跟踪发送 / 失败。

---

## 6. 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 测试发失败 | secret 错 | 重填 |
| 码没收到 | 模板没批 | 等审批 |
| 发太多 | 限流 | 查 `sms_rate_limits` |
| 国际发不出 | 国家不支持 | 查 `/countries` |
