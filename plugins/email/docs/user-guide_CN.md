# 邮件服务 — 使用指南

本指南面向 **运营**，指导你配置 SMTP/IMAP 并使用内置邮件 UI。

---

## 1. 前置条件

- VeroRun App ≥ 0.10.0。
- SMTP 账号（Gmail 应用密码 / Outlook / QQ / 企业邮箱）。
- 可选：IMAP 收件。

---

## 2. 配置

1. **用户与支持 → Email Service → Settings**。
2. 从 `/providers` 选提供商（自动填 host/port）。
3. 填 SMTP 用户 / 密码 / from。
4. IMAP host / port（可选）。
5. **测试配置** → 应返回成功。

---

## 3. 用邮件 UI

- **收件箱** — 读来信（IMAP）。
- **写信** — 发送；附件除黑名单外都允许。
- **草稿** — 保存 / 续编。
- **已发** — 历史。
- **联系人** — 从已发自动收集。

---

## 4. 股票告警

- 设 `alert_recipient` → 股票告警与晨报走邮件。
- 留空 = 跳过邮件通道。

---

## 5. 安全护栏

- 每日配额（默认 200）防误发垃圾。
- 附件黑名单阻止可执行文件外发。
- 内网 SMTP 默认被拒，除非开 `allow_private_targets`。

---

## 6. 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 发送失败 | SMTP / 鉴权错 | **测试配置** |
| 收件箱空 | IMAP 没配 | 填 IMAP host/port |
| 附件被拒 | 扩展名黑名单 | 改名 / 打 zip |
| 配额到顶 | 每日上限到 | 等；调大 `daily_send_quota` |
| 测试拒绝 localhost | SSRF 防护 | 仅在可信内网开 |
